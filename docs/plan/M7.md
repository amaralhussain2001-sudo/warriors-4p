# M7 — Robustness (exit criteria written before work started, 2026-10-12)

Goal (BRIEF §7 M7, §8.1-8.3): long sessions, disconnect and reconnect, timeouts, packet loss and jitter, hunting for
crashes and softlocks, and regression tests of single-player, original two-player play and optional content.
Every result is labelled SINGLE-PC / LAN / INTERNET, bots or humans, impairment simulated or not. SINGLE-PC and bot
results never stand in for LAN/INTERNET or human results.

## Exit criteria (all required)
| # | Criterion | Measurement / evidence |
|---|---|---|
| 1 | **Long session:** 4 instances in lockstep for >= 60 min with random bots through at least one level change (mission end or checkpoint restart), 0 hash mismatches, 0 crashes / TLB misses, 0 softlocks (the poll counter keeps advancing) | `tests/m2/m2_run4.py` with `--polls` long enough, `evidence/M7/long_*.json` |
| 2 | **Disconnect and reconnect through the real connection path** (package launchers + w4p-net helpers): an outage shorter than the timeout recovers with 0 mismatches (T1g); a longer one reaches the host's choice (continue / restart) with the right result on every remaining PC | package self-test or local4.py runs, logs |
| 3 | **Impairment:** reproducible simulated latency (RTT 50 / 100 / 150 ms), jitter (+-20 ms), loss (1 % and 5 %) and reordering, each for >= 10 min with 4 instances: 0 unrecovered desyncs; measured input delay (frames), stall time per minute and fps reported for each | `evidence/M7/imp_*.json`; method documented (built-in impairment or external tool) |
| 4 | **Crash and softlock hunt:** every main-story mission smoke-tested with 4 players and random bots after all M6 fixes (smoke2 and later batches), plus GAME OVER -> "Last checkpoint" and checkpoint reloads in at least 6 missions; every crash or softlock found has a finding and a fix or a documented status | `evidence/M6/smoke2_*`, `evidence/M7/restart_*` |
| 5 | **Regression, single-player:** with the mod's patch file installed and W4P off, single-player starts a new story, plays Mission 1 to its first checkpoint, pauses, saves and loads on a fresh memory card; behaviour matches the unmodified game in the checked points | runs + screenshots, `evidence/M7/reg_1p_*` |
| 6 | **Regression, original local two-player:** two pads on one emulator (no W4P), player 2 joins with Start, split screen, both fight, player 2 drops out and re-joins | `evidence/M7/reg_2p_*` |
| 7 | **Optional content at its original player count:** flashback missions, Rumble mode and the arcade/minigames that the menus offer load and run for >= 2 min with the mod installed (1 or 2 players as the original) | `evidence/M7/opt_*` |
| 8 | **Measurements (§8.3)** with conditions: RTT and input delay in frames, jitter and loss tolerance, bandwidth per player, desync frequency and resync time, CPU and memory per instance | `docs/reports/M7_report.md` table |
| 9 | **Originals unchanged** | `tools/hash_inputs.py`, HASHES.md |

Human parts (feel of controls under latency, LAN/INTERNET outages with real routers) are prepared as test sheets for
the user; they do not block the SINGLE-PC criteria above but are listed as open in the report until done.
