# M6 — Mission-by-mission enablement (exit criteria written before work started, 2026-10-12)

Goal (BRIEF §7 M6, §8.4): every main-story mission (1-18, plus the hub interludes) reaches exactly one final status of
§8.4 with recorded evidence. Companion replacement or preservation, script adaptation, and per-mission testing.

## Exit criteria (all required)
| # | Criterion | Measurement / evidence |
|---|---|---|
| 1 | **Smoke test per mission (SINGLE-PC, 4 instances, bots):** the mission starts, players 3-4 can join (companion taken over, or spawned Warrior with its own model when one fits), combat runs, 4 instances stay in lockstep for >= 10 min, no crash / softlock | `tests/m6/mission_smoke.py`, `evidence/M6/smoke_m<NN>.json` |
| 2 | **Per-mission fixes** for every problem the smoke test or the playthroughs find (companions, scripts that know only player 1-2, starting items for players 3-4 R-29, objectives) - each with a finding and a re-test | FINDINGS, re-test evidence |
| 3 | **Restart and checkpoint per mission:** GAME OVER -> "Last checkpoint" and a checkpoint reload work with 4 players (R8, F-0153) | per-mission run |
| 4 | **Completion from start to end** with four players: needs humans (bots cannot do objectives) - LAN with the user's PCs first, then INTERNET with the user's friends (§8.4 FOUR-PLAYER ONLINE VERIFIED); 2- and 3-player checks too | test sheets filled by the user, session logs |
| 5 | **Hub interludes** (D4 A: players 2-4 stay connected and in sync with a waiting screen while the host does the required hub steps) | per-interlude run |
| 6 | **Mission status table** in `docs/MISSIONS.md`: one final §8.4 status per mission with evidence | MISSIONS.md |

Status labels until then: NOT YET TESTED / IN PROGRESS. A mission is not verified while any required test is incomplete.
Criterion 4 cannot be met on SINGLE-PC: the smoke tests prepare the human sessions and find problems first.
