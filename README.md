# warriors-4p

Research and (after approval) implementation project to let up to four players play the story campaign of
The Warriors (PS2, SLUS-21215) online, each on their own PC with PCSX2.

Current status: **Stage 1 (investigation and plan) complete; waiting for approval.** Start with `docs/STATE.md` and
`docs/plan/STAGE1_PLAN.md`. The brief is `docs/BRIEF.md`.

This repository contains only our own tools, notes and patches. It never contains the game, the ISO, a BIOS,
extracted game files, savestates or memory cards. Players must use their own legally obtained copies.
